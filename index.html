    How I work

    Three rules I keep.

    1. 01

      Wait for conditions, not clocks.

      A fixed sleep is a guess. I wait for what the page or the API is actually doing, which makes tests both faster and steadier.

    2. 02

      Make failures explain themselves.

      An assertion message, a log line and a screenshot should tell you what broke and where, before anyone reaches for the rerun button.

    3. 03

      Find the root cause.

      A red test gets investigated the same day. It is a product defect, an environment problem or a bad test, and each one has a different fix.
