# rahul-c-h.github.io

Source for my portfolio site: https://rahul-c-h.github.io/

A plain static site with no build step.

- `index.html`: page content
- `styles.css`: layout and theme
- `script.js`: scroll reveal, the hero animation and the test-runner demo

GitHub Pages serves the `main` branch root, so every push updates the site.
To preview locally, open `index.html` in a browser.
